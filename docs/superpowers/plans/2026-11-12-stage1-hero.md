# Stage 1: Hero Vertical Slice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A runnable, deployable first viewport: the visitor's request is observed live at the edge and drawn as an iridescent thin-film ribbon through a 3D hairline drawing of the system, on cloud-white vellum. Static, reduced-motion, night and mobile versions all work.

**Architecture:**
- Vite + React SPA, prerendered to static HTML at build time (SSR render, then hydrate).
- One topology module feeds both the static SVG drawing (first paint, fallback, reduced motion, low tier) and the lazy R3F scene.
- A Vercel Edge function returns the visitor's edge data; the client measures RTT and falls back to `Intl` data.

**Tech Stack:**
- Bun; Vite 8, React 19.3, TypeScript 5.9
- three 0.187, @react-three/fiber 9.8, @react-three/drei 10.7
- Vitest 5
- @fontsource-variable/hanken-grotesk, @fontsource/b612-mono

**Spec:** `docs/design.md`, direction contract `.impeccable/surfaces/index-html.md`, product `PRODUCT.md`

### Task 2: Observation (edge function + card)

**Files:**
- Create: `api/whoami.ts`, `src/lib/observe.ts`, `src/lib/observe.test.ts`, `src/components/ObservationCard.tsx`
- Modify: `vite.config.ts` (dev middleware), `src/components/Hero.tsx`

**Interfaces:**
- Consumes: `content`
- Produces:
  ```ts
  type Observation = { id: string; city: string; country: string | null; region: string | null; rttMs: number | null; localTime: string; source: 'edge' | 'fallback' }
  parseVercelId(h: string | null): { region: string | null; id: string }
  buildObservation(edge: Partial<{ id: string; city: string; country: string; region: string }> | null, rttMs: number | null, now: Date, tz: string): Observation
  fetchObservation(): Promise<Observation>
  ```

- [ ] **Step 1: Write the failing tests** in `observe.test.ts`:
  - `parseVercelId('bom1::iad1::abcde-1700000000000-7f3a9c2b')` → `{ region: 'bom1', id: '9C2B' }`
  - `parseVercelId(null).region === null`, with an `id` matching `/^[0-9A-F]{4}$/`
  - `buildObservation({ city: 'S%C3%A3o%20Paulo', region: 'gru1', id: '7F3A' }, 84, …).city === 'São Paulo'`
  - `buildObservation(null, null, new Date('2026-11-12T13:42:00Z'), 'Asia/Karachi')` gives `{ city: 'Karachi', region: null, source: 'fallback', localTime: '18:42' }`, and the serialized output never contains `"undefined"`
- [ ] **Step 2:** Run `bunx vitest run src/lib/observe.test.ts`. Expected: FAIL (module missing).
- [ ] **Step 3: Implement.**
  - `observe.ts`: the fallback city is the last segment of the tz with `_` replaced by a space. `localTime` is `HH:mm` via `Intl.DateTimeFormat('en-GB', { hour, minute, timeZone })`.
  - `fetchObservation`: time `fetch('/api/whoami', { cache: 'no-store' })` with `performance.now()`, use a 2500 ms `AbortSignal.timeout`, and catch to the fallback.
  - `api/whoami.ts`: `export const config = { runtime: 'edge' }`. It returns JSON from `x-vercel-ip-city`, `x-vercel-ip-country` and `parseVercelId(x-vercel-id)`, with `cache-control: no-store`.
  - Dev middleware in `vite.config.ts` returns `{ city: 'Localhost', region: 'dev1', id: 'DEV0' }`.
- [ ] **Step 4:** Rerun the tests. Expected: PASS.
- [ ] **Step 5: Build `ObservationCard`.**
  - It renders a `pending` state on the server and on first client render (time `--:--`, "observing…"), then fills on `useEffect`. This avoids a hydration mismatch.
  - Lines: `Observed 18:42 · ● LIVE`, `Your request · Karachi → bom1`, `84 ms round trip · req 7F3A`. Use `aria-live="polite"`.
  - The LIVE dot is drawn violet. With source `fallback`, it reads `Your request · Karachi (edge unknown)`.
- [ ] **Step 6: Verify.** Run `bun run dev`: the card fills with Localhost/dev1. In DevTools, block `/api/whoami`: the card shows the timezone city and no `undefined`.

### Task 3: Quality tiers + 3D scene

**Files:**
- Create: `src/lib/quality.ts`, `src/lib/quality.test.ts`, `src/scene/Scene.tsx`, `src/scene/RequestRibbon.tsx`
- Modify: `src/App.tsx`

**Interfaces:**
- Consumes: `NODES`, `REQUEST_PATH`
- Produces:
  - `type Tier = 'high' | 'mid' | 'low' | 'static'`
  - `detectTier(env: { webgl: boolean; reducedMotion: boolean; cores: number; memoryGB: number | null; coarsePointer: boolean; width: number }): Tier`
  - `readEnv(): Parameters<typeof detectTier>[0]`

- [ ] **Step 1: Write the failing tests:**
  - `webgl: false` → `'static'`
  - `reducedMotion: true` → `'static'`
  - `coarsePointer && (cores <= 4 || memoryGB <= 3)` → `'static'` (weak phones get the SVG)
  - `coarsePointer` otherwise → `'low'`
  - `cores <= 4` → `'mid'`
  - default desktop → `'high'`
- [ ] **Step 2:** Run `bunx vitest run src/lib/quality.test.ts`. Expected: FAIL.
- [ ] **Step 3:** Implement `quality.ts`. `readEnv` uses `matchMedia` and `navigator.hardwareConcurrency` / `deviceMemory`, and tests WebGL with `canvas.getContext('webgl2')`.
- [ ] **Step 4:** Rerun the tests. Expected: PASS.
- [ ] **Step 5: Build `Scene.tsx`.**
  - Defaults: `<Canvas dpr={tier==='high' ? [1, 2] : [1, 1.5]} gl={{ antialias: tier !== 'low', alpha: true }} frameloop="always">`, with an orthographic-feeling perspective camera (fov 30) looking slightly down.
  - **Volumes:** each node is a `MeshStandardMaterial` box at `--mist`, opacity 0.55, `depthWrite: false`, plus `<Edges>` in slate at 1px.
  - **Lighting:** soft hemisphere and directional light only.
  - **Motion:** the drawing slowly parallaxes to the pointer (max 3°, damped). The ribbon head (a violet sphere) travels the path every 6 s.
  - **Ambient droplets:** instanced spheres in slate at 30% alpha moving along connectors; 60 on high, 24 on mid, 12 on low.
  - **PerformanceMonitor:** `onDecline` → `mid`, and on a second decline → swap to static.
  - **Context loss:** `webglcontextlost` → swap to static.
- [ ] **Step 6: Build `RequestRibbon.tsx`.**
  - Geometry: `TubeGeometry(CatmullRomCurve3(REQUEST_PATH), 240, 0.035, 8)` with a custom `ShaderMaterial`.
  - The thin-film colour comes from the view angle, via the fragment snippet below.
  - The ribbon reveals to the head position via a `uProgress` uniform (`discard` when `vUv.x > uProgress`) and stays drawn once complete.
  ```glsl
  // thin-film: optical path difference d·cosθ maps to a mint→rose→violet palette
  float c = clamp(dot(normalize(vNormal), normalize(vView)), 0.0, 1.0);
  float t = fract(uThickness * (1.0 - c) + vUv.x * 0.35 + uTime * 0.03);
  vec3 col = t < .5 ? mix(uMint, uRose, t * 2.) : mix(uRose, uViolet, (t - .5) * 2.);
  gl_FragColor = vec4(col, 0.92);
  ```
- [ ] **Step 7: Mount the scene in `App.tsx`.**
  - After hydration, run `requestIdleCallback` (falling back to `setTimeout(…, 200)`) → `detectTier(readEnv())`. If the tier is not `static`, `lazy(() => import('./scene/Scene'))` into the drawing slot.
  - The canvas fades in over the SVG (opacity 0→1, 600 ms ease-out-expo), then the SVG becomes `aria-hidden` and invisible.
  - The SVG stays the accessible description: an `<svg role="img" aria-labelledby>`.
- [ ] **Step 8: Verify.**
  - Run `bun run build`. The `Scene` chunk is separate in `dist/assets`, and the main chunk is under 90 kB gzip.
  - In the browser, the 3D draws with no console errors.
  - With reduced motion emulated in DevTools, the SVG only shows and no canvas exists.
