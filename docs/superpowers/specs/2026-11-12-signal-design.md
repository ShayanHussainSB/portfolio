# SIGNAL: portfolio redesign

User direction: a single high-tech landing page, animated from top to bottom, with an intentional strong palette. Colors and execution delegated. Preserve the real demos, truthful claims, contact, photos, React/Vite, static prerender, and mobile accessibility.

Design call: carbon black, warm white, signal orange. An engineered kinetic core fills the hero's right side, with bold editorial lettering on the left. Project names become large typographic landmarks; each demonstration remains working. One continuous page with navigation, about, interactive work, record and contact. The request data remains live and labels fallback honestly.

Considered: polishing pale drafting (too restrained for the new request); neon dashboard (too familiar and noisy); sculptural industrial editorial (chosen by implementer under delegated design choice). The last gives strong silhouettes, physical motion and readable engineering proof.

Motion: rotating layered core with pointer parallax; entrance choreography; section reveals; active navigation; ambient signal motion in visible demo panels; responsive hover states. No scroll hijacking. Reduced motion disables ambient and entrance animation. Canvas pauses out of view and on hidden tabs; static geometric fallback remains.

Non-goals: changing demo algorithms, inventing career claims, testimonials, or a CV; implementing every speculative secret in the old plan; changing deployment providers.
